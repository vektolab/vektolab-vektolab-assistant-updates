# Genesis 2.0 — reinicio de arquitectura

Esta versión no es un parche de la física anterior.

## UX
- Vekto permanece visible como acompañante de escritorio.
- Clic: abre/cierra el menú.
- Arrastre: mueve el avatar.
- No hay gravedad ni rebote de pantalla.
- El avatar tiene una reacción visual pequeña al arrastre/soltar para conservar personalidad.
- El menú es una ventana independiente y se posiciona respecto del avatar.

## Catálogo
- Generadores y Diseños en una sola interfaz.
- Búsqueda local por nombre, descripción, palabras clave y slug.
- `Ver todos` abre el catálogo ampliado.
- Los generadores se abren en una ventana de trabajo separada.

## Negocio
- Los generadores locales mantienen Patreon.
- El contenido puede actualizarse desde GitHub sin sustituir el ejecutable.
- Se mantiene el canal de actualización de la aplicación.
