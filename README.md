# Vektolab Assistant

Asistente de escritorio de Vektolab para Windows.

## Actualizaciones

### Programa
Los cambios del programa se publican mediante GitHub Releases usando tags `vX.Y.Z`.

### Generadores y contenido
Los generadores se mantienen en `content/`. Se pueden agregar o modificar sin crear un nuevo instalador.

El Assistant descarga automáticamente los cambios desde GitHub.

Consulta `CONTENT-GITHUB.md` para el procedimiento.
