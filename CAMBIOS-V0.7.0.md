# Vekto v0.7.1

Corrección del clic del avatar y apertura del panel principal.

- Al hacer clic normal sobre el avatar, el panel principal vuelve a abrirse.
- El panel no se cierra por un cambio de foco inmediato.
- El avatar sigue siendo una ventana independiente y no se mueve al abrir el panel.
- El panel se coloca tomando la posición actual del avatar.
- El clic derecho mantiene el menú contextual.
- El arrastre y la física del avatar siguen funcionando.
