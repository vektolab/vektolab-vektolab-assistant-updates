# Vektolab Assistant — Genesis (v1.0.0)

- Se elimina por completo el rebote, la inercia y la física del avatar.
- Vekto permanece exactamente donde el usuario lo deja.
- El avatar solo se mueve mientras el usuario lo arrastra.
- Un clic sobre Vekto abre el menú. Otro clic sobre Vekto lo cierra.
- El menú usa una ventana independiente y no modifica la posición del avatar.
- El menú se coloca directamente encima del avatar, alineado con su esquina inferior derecha.
- El avatar permanece por encima del menú y de la barra de tareas.
- El tamaño del menú principal se ajusta al diseño mostrado: 455 × 680 px.
- La posición del avatar se guarda entre ejecuciones.
- La versión de aplicación es `1.0.0` y el tag de GitHub correspondiente es `v1.0.0`.
