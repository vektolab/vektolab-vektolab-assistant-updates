VEKTOLAB — paquete preparado para Cloudflare Pages

Este paquete deja los generadores públicos y protege solamente las descargas mediante Patreon.

IMPORTANTE:
1) Antes de publicar, configurar el nuevo cliente Patreon API v2.
2) Configurar el Worker de Cloudflare con el archivo cloudflare-worker-patreon-v2.js incluido fuera de este paquete.
3) El archivo patreon-gate.js ya apunta al Worker antiguo mostrado en Cloudflare:
   https://round-moon-e1f4vektolabs-gate.vektocreativeteam.workers.dev
4) No se incluyen secretos ni Client Secret en este paquete.

Para Cloudflare Pages: subir el CONTENIDO de esta carpeta (index.html, generadores/, imagenes/, etc.).
