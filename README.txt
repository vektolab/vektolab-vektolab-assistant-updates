VEKTOLAB ASSISTANT 0.5.2

1) Ejecuta `npm install` una sola vez para preparar el proyecto de desarrollo.
2) Para probarlo, ejecuta `npm start` o usa `Iniciar Vektolab Assistant.bat`.
3) Para distribuirlo, genera el instalador con `npm run dist`.

El programa tiene dos sistemas de actualización:
- Actualización del programa mediante GitHub Releases.
- Actualización automática de generadores y archivos desde la carpeta `content/` de GitHub.

Consulta `CONTENT-GITHUB.md` para agregar nuevos generadores sin crear un nuevo instalador.
